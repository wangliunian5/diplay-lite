# DiPlay Lite（中文社区维护分支）

为低配安卓车机（Android 4.1+ / 各 OEM 平台）提供有线及无线 CarPlay 的社区适配版，
基于 [shihabal3amri/DiPlay](https://github.com/shihabal3amri/DiPlay) 及
[shilapi/xcertplay](https://github.com/shilapi/xcertplay) 接收器基础独立演化，
DiAuto 风格界面。本分支面向**个人研究、车友交流与兼容性维护**，不提供商业销售、
付费授权或商业技术支持。该定位不改变原代码许可证赋予的权利；素材另有许可限制的，
见下文。

部分功能（特定平台的有线 CarPlay、adb 自举、NCM 解绑守护等）依赖**修改用户
自有车机的系统**（root/adb）。此类操作可能导致失去保修甚至设备变砖，后果
完全由用户自行承担。诊断日志仅在用户**主动触发上传**时才会离开设备；日志
上传凭据由构建时注入，绝不入库。
