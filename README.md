# DiPlay Lite

基于开源项目 [DiPlay](https://github.com/shihabal3amri/DiPlay)（© shihabal3amri，GPL-3.0）的社区分支，
面向老款及各平台安卓车机（API 16+）的兼容适配版本。

- 上游项目：https://github.com/shihabal3amri/DiPlay
- 本分支修改：老车机兼容适配（API16+）、设置界面重构、系统诊断取证增强、
  低配设备视频性能优化、多平台有线/无线 CarPlay 适配；1.1.x 线新增有线 NCM
  全链路加固（NTB16 失步窗口化重同步、MUSB 单端点 wedge 对策、0x4301 会话重发
  预算、内核 NCM 接口解绑守护）、iOS16 mDNS 有线发现、ECARX/鼎微等平台专项
  适配、root USB 取证探针与日志上传通道、车标个性化选择
- native/ 内含 Opus 编解码器（BSD 许可，详见 native/jni/opus/COPYING）

## 构建

- Android Studio 或命令行 `gradlew assembleRelease`（需 JDK 17）
- `native/` 为 Opus JNI 源码（NDK 预编译产物随仓库分发）
- 日志上传凭据：如需启用 Gitee 日志上云，在 `local.properties`（不入库）中添加
  `GITEE_LOG_TOKEN=<你自己的 token>`；未配置时上传功能自动降级为手动发送路径
- **注意**：`app/src/main/assets/offline-mfi/`（MFi 认证身份资产）与
  `app/src/main/assets/car-logos/`（车标素材，权利归各自权利人）均不随本仓库公开，
  需自行准备后放入对应目录：MFi 资产缺失时 CarPlay 认证无法通过（代码可正常编译），
  车标素材缺失时车标选择页显示为空，其余功能不受影响
