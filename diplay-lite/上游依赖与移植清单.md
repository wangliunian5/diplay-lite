配合 LICENSE 与 README 免责声明中的署名要求。

## 一、整体基线——产品地基来自上游源码

diplay-lite 的 `shared` 模块（99 个 Kotlin 文件）取自上游 CarPlay 接收器协议栈，涵盖：

- iAP2 握手与 MFi 配对认证（PairSetup / PairVerify / SRP6a）
- AirPlay 会话与音视频引擎（含 Opus 编解码，native/ 内 BSD 许可）
- NCM / usbmuxd 有线传输层、Wi-Fi 无线链路层
- Bonjour / mDNS 服务发现
- BYD HUD 桥等车型对接层

移植方式为 **API 16 裁剪适配**而非原样搬运：16 类兼容改造（Closeable 替换、
蓝牙/热点反射回退、JmDNS 强制 4.x、MediaCodec/AudioTrack/AudioRecord 兼容、
lint NewApi 归零等）。App 整体形态（免越狱车机端接收器、实验性 MFi 身份、
本地认证）沿袭上游模式。

## 三、自研部分（非移植）

以下为自主设计与实现，仅在个别设计思想处参考上游 issue/PR：

- 无线连接提速：BT 唯一 bonded 直选、Bonjour 整体后台化、热点保留复用
- TS7 有线 CarPlay 四层打通：NCM 选组反转（MUSB EP 0x07 TX 丢弃规避）、
  建立看门狗、NTB16 失步重同步+风暴窗口化、WiredBonjourAdvertiser、WiredNcmGuard
- EU5 麦克风兜底矩阵（源×采样率×声道全试开+线性重采样）
- AirPlay 监听端口三层回退、EU5 看门狗误杀修复、8815 渲染链修复、
  系统诊断取证体系、开源声明弹窗

## 四、上游镜像分支

用于 diff 对照，从未合并进产品线。
